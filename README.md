# 4chan /twg/ & /utwg/ Daily Digest Bot

Автоматический бот на **PHP 8.2+**, который ежедневно собирает обсуждения из двух главных тредов айтишников на имиджборде 4chan (`/g/`):
- **/twg/** — *Tech Workers General* (трудоустроенные айтишники, галеры, лейоффы, оверэмплоймент).
- **/utwg/** — *Unemployable Tech Workers General* (безработные вкатуны и сеньоры, вой об отсутствии работы, сычевание, литкод).

Бот подтягивает посты за вчерашний день, восстанавливает контекст диалогов (если анон вчера отвечал на реплику позавчера), генерирует единую сатирическую выжимку в сленге имиджборд через бесплатный LLM API (Groq Llama 3.3 70B или Google Gemini), публикует дайджест и все прикрепленные картинки альбомами в Telegram-канал, а также отправляет Email-оповещения в случае сбоев.

---

## ⚡ Особенности реализации

- **Умное дерево контекста**: Если анон вчера в `00:15` ответил на пост от `23:45` позавчера, бот находит родительский пост и передает его в ИИ с пометкой `[Контекст]`, чтобы суть спора не терялась.
- **Имиджборд-стиль**: Промпт настроен на сочный язык (аноны, вкатуны, сеньоры, галеры, гребцы, кукож, оферы, сычевание, лейоффы).
- **Строгий лимит Telegram**: Выжимка укладывается в одно сообщение Telegram (до 3500 символов), чтобы лента канала оставалась аккуратной.
- **Пакетная публикация картинок**: Картинки за вчерашний день пакуются в аккуратные альбомы до 10 штук (`sendMediaGroup`) с паузами во избежание флуд-контроля.
- **Email-алерты**: Оповещения на почту через SMTP, если один из тредов не найден в каталоге, если за день было 0 постов, либо при критической ошибке.
- **100% Бесплатно**: Можно запускать без аренды серверов через **GitHub Actions** (расходуется ~15 минут из 2000 бесплатных минут в месяц).

## 🔑 Получение бесплатных API ключей

### 1. Бесплатный AI API (Groq или Gemini)
- **Groq (Рекомендуется)**:
  1. Зарегистрируйтесь на [console.groq.com](https://console.groq.com/).
  2. Перейдите в раздел **API Keys** и создайте новый ключ (`gsk_...`).
  3. Используется быстрая модель `llama-3.3-70b-versatile` (бесплатно).
- **Google Gemini**:
  1. Перейдите на [aistudio.google.com](https://aistudio.google.com/).
  2. Создайте бесплатный API ключ.
  3. Используется модель `gemini-2.0-flash` (окно контекста 1M токенов).

### 2. Telegram Bot & Канал
1. Создайте бота через [@BotFather](https://t.me/BotFather) в Telegram и сохраните токен (`TELEGRAM_BOT_TOKEN`).
2. Создайте публичный или приватный канал.
3. Добавьте созданного бота в **администраторы канала** с правом публикации сообщений.
4. Укажите `TELEGRAM_CHAT_ID` (например, `@my_digest_channel` или ID вроде `-1001234567890`).

### 3. Почта для алертов (SMTP)
- **Gmail**: включите 2-Step Verification и создайте «Пароль приложения» (App Password). Формат: `smtp://your_email@gmail.com:app_password@smtp.gmail.com:587`.
- **Resend**: зарегистрируйтесь на [resend.com](https://resend.com/) (100 писем/день бесплатно) и получите SMTP-ключ. Формат: `smtp://resend:re_123456@smtp.resend.com:587`.
- **Яндекс**: пароль для внешних приложений. Формат: `smtp://user@yandex.ru:pass@smtp.yandex.ru:465`.

## 🚀 Установка и локальный запуск

### 1. Клонирование и установка зависимостей
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd utwg_digest
composer install
```

### 2. Настройка `.env`
Скопируйте пример конфига:
```bash
cp .env.example .env
```
Заполните ваши ключи и настройки в `.env`.

### 3. Команды запуска
```bash
# Тестовый запуск без отправки в Telegram (Dry run)
php run.php --dry-run

# Тестовый запуск без вызова AI (только проверка парсинга и картинок)
php run.php --dry-run --skip-ai

# Запуск за конкретную дату (ГГГГ-ММ-ДД)
php run.php --date=2026-09-21 --dry-run

# Обычный боевой запуск
php run.php
```

## ☁️ 100% Бесплатный запуск на GitHub Actions (Без сервера)

В репозитории уже настроен workflow [`.github/workflows/daily_digest.yml`](.github/workflows/daily_digest.yml), который запускается автоматически каждый день в **04:00 UTC** (07:00 по МСК):

1. Создайте репозиторий на GitHub (публичный или приватный).
2. Запушьте код проекта в репозиторий.
3. Перейдите в **Settings** -> **Secrets and variables** -> **Actions** и добавьте переменные в **Repository secrets**:
   - `GROQ_API_KEY` (или `GEMINI_API_KEY`)
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
   - `ALERT_EMAIL_TO`
   - `SMTP_DSN`
4. Бот будет запускаться по расписанию, брать данные за вчерашний день и публиковать пост с картинками в канал.
5. Также доступен ручной запуск во вкладке **Actions** -> **Parse 4chan & Post Digest** -> **Run workflow**.

## 🖥 Альтернатива: запуск на собственном VPS через Cron

Если вы предпочитаете запускать скрипт на VPS, добавьте задачу в `crontab -e`:

```cron
# Запуск ежедневно в 04:00 утра
0 4 * * * cd /path/to/utwg_digest && /usr/bin/php run.php >> /var/log/chan_digest.log 2>&1
```
